API Documentation

POST /api/ingest/file

Upload a file for ingestion. Form-data: file, tags (comma-separated).

POST /api/ingest/text

Submit plain text. JSON: { text, tags }.

POST /api/ingest/url

Submit a URL for web clipping. JSON: { url, tags }.

GET /api/status

Get job queue counts: activeCount, pendingCount, completedCount, failedCount.

GET /api/search

Search vault. Query param: q (search query).

POST /api/chat/llama

Chat with local Llama. JSON: { message, history }.
