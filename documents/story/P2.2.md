# Story P2.2 — Ingestor Real Logic

## Overview

Ingestor reads files from `$RAW_DIR`, validates them, and creates Document records for downstream processing. Enqueues TextExtractor messages to begin the extraction pipeline.

## Implementation Requirements

- Read files from configured RAW_DIR directory
- Create Document records with initial metadata
- Copy structured files to incoming vault area if appropriate
- Route to TextExtractor via Coordinator
- Handle file not found and read errors
- Log file ingestion with size and type information

## Acceptance Criteria

- Files in RAW_DIR are processed and Document records created
- Document status transitions correctly through the ingestion stage
- File validation catches missing or corrupt inputs
- Messages properly route to TextExtractor for processing
