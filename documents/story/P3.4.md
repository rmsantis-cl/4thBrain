# Story P3.4 — Smoke Test

## Overview

Manual browser-based smoke test verifying the complete system end-to-end. User loads the web UI, submits test documents via form, watches pipeline progress through the dashboard.

## Test Procedure

1. Start application: `gradle bootRun`
2. Open browser: `http://localhost:8080/chat`
3. Submit test file via form (PDF, DOCX, or plain text)
4. Observe document appear in status dashboard
5. Watch status progress through stages: ingesting → extracting → classifying → indexing → indexed
6. Verify final document indexed and searchable
7. Check database records created (Document, Classification, DocumentTag)
8. Verify vault files in correct locations

## Pass Criteria

- UI loads without errors
- File upload succeeds
- Document appears in dashboard
- Status transitions visible in real-time
- Document reaches indexed state
- No errors in application logs

## Acceptance Criteria

- Smoke test passes with at least one document type (PDF or DOCX recommended)
- Manual walkthrough document created for future smoke tests
- Known limitations documented (if any)
