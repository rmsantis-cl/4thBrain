# Story P3.5 — Upgrade to JUnit 5

## Overview

Migrate all test code from JUnit 4 to JUnit 5 (Jupiter). JUnit 5 provides better annotation support, improved parameterized tests, lifecycle callbacks, and cleaner extension model.

## Implementation Requirements

- Update `build.gradle`: replace `junit:junit:4.x` with `org.junit.jupiter:junit-jupiter`
- Replace `@RunWith` and `@Rule` with JUnit 5 equivalents
- Update test class annotations: `@Test`, `@DisplayName`, lifecycle annotations
- Migrate Spring Boot test annotations to work with Jupiter
- Update Mockito integration for JUnit 5
- Update test base classes to use JUnit 5 lifecycle
- Remove JUnit 4 specific imports

## Key Changes

| JUnit 4 | JUnit 5 |
|---------|----------|
| `@RunWith(SpringRunner.class)` | `@SpringBootTest` (works with Jupiter) |
| `@Rule` | `@ExtendWith` (extension model) |
| `@Before` / `@After` | `@BeforeEach` / `@AfterEach` |
| `@BeforeClass` / `@AfterClass` | `@BeforeAll` / `@AfterAll` |
| `@ParameterizedTest` (add-on) | `@ParameterizedTest` (built-in) |

## Compatibility

- Spring Boot 3.2.0 includes Jupiter in `spring-boot-starter-test`
- MockitoExtension for better Mockito integration

## Acceptance Criteria

- All tests migrated to JUnit 5 annotations
- `gradle test` passes with Jupiter engine
- No JUnit 4 imports in test classes
- All existing test functionality preserved
- IDE recognizes tests as JUnit 5
