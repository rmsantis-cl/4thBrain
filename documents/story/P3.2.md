# Story P3.2 — Integration Tests

## Overview

Integration tests for message flows through multiple actuators. Mock external services (Ollama, vault I/O, Smart Connections) but test real Coordinator message dispatch and queue interactions.

## Implementation Requirements

- Test end-to-end document flow: Ingestor → TextExtractor → Classifier → Indexer
- Test branching: Clipper path for URLs
- Test scheduled Briefing integration
- Mock OllamaClient and file I/O
- Verify document status transitions through pipeline
- Verify proper message routing
- Verify concurrent message handling

## Test Scenarios

- Single document through full pipeline
- Multiple documents concurrently
- Error recovery (one stage fails, pipeline continues)
- URL ingestion path
- File upload path

## Framework

- Spring Boot Test (`@SpringBootTest`)
- Testcontainers (if needed for database isolation)
- Mockito for external service mocks

## Acceptance Criteria

- Full pipeline message flows tested end-to-end
- Concurrent processing verified
- Error conditions handled gracefully
- Document status progression correct
- `gradle integrationTest` passes
