# Story P3.3 — REST API Tests

## Overview

MockMvc tests for all REST endpoints. Verify payloads accepted, responses returned, database records created.

## Endpoints to Test

- `POST /api/ingest/file` — file upload
- `POST /api/ingest/text` — text ingestion
- `POST /api/ingest/url` — URL ingestion
- `GET /api/status` — document status counts
- `GET /api/search` — document search (stub in Phase 1)
- `POST /api/chat/llama` — chat endpoint (stub in Phase 1)
- `GET /admin/db` — admin database view (stub in Phase 1)

## Implementation Requirements

- Test request/response format
- Verify Document records created
- Verify correct status codes
- Verify error handling (invalid input, missing fields)
- Verify response envelope (consistent shape across endpoints)

## Framework

- `@WebMvcTest` for controller testing
- MockMvc for HTTP simulation
- Spring Test for database setup

## Acceptance Criteria

- All endpoints have MockMvc tests
- Happy path and error cases tested
- Response formats consistent and validated
- `gradle test` passes all API tests
