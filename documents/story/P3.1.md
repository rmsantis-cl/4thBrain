# Story P3.1 — Unit Tests

## Overview

JUnit 5 unit tests for each actuator (Ingestor, TextExtractor, Classifier, Indexer, Briefing). Mock all dependencies (Coordinator, OllamaClient, DatabaseService, file I/O). Verify process() logic and queue handling.

## Implementation Requirements

- Test each actuator's process() method independently
- Mock dependencies: Coordinator, OllamaClient, DatabaseService
- Verify correct document status transitions
- Verify correct routing to next stage via Coordinator
- Verify error handling and recovery
- Verify logging of key events

## Framework and Tools

- JUnit 5 (Jupiter)
- Mockito for mocking
- Assertions from AssertJ or standard JUnit

## Test Coverage

- >80% code coverage of actuator logic
- Normal path (successful processing)
- Error paths (invalid input, upstream failure)
- Edge cases (null document, empty queue message)

## Acceptance Criteria

- `gradle test` passes all unit tests
- >80% code coverage of actuator process() methods
- All actuators covered (Ingestor, TextExtractor, Classifier, Indexer, Briefing)
- Tests use descriptive names and clear assertions
