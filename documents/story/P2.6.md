# Story P2.6 — Briefing Real Logic

## Overview

Briefing is a scheduled actuator (6 AM daily) that queries recent indexed documents, constructs a synthesis prompt, calls OllamaClient, and writes the briefing to the vault.

## Implementation Requirements

- Query DocumentRepository for documents indexed within the last 24 hours (or configurable window)
- Build LLM prompt from document summaries and metadata
- Call OllamaClient with synthesis prompt (gated by ConcurrencyGate)
- Parse LLM response to generate briefing summary
- Write briefing to vault with timestamp
- Log successful briefing generation with document count and summary length
- Handle edge cases (no recent documents, LLM timeout, write failures)

## Scheduling

- Implement as @Scheduled bean
- Cron expression: `0 0 6 * * *` (6 AM daily)
- Configurable via application.yaml

## Acceptance Criteria

- Briefing generates daily at 6 AM
- Recent documents (24h window) included in synthesis prompt
- LLM-generated briefing written to vault with proper naming/dating
- No briefing generated if no documents available
- Errors logged without blocking other pipeline stages
