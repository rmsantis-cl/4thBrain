# Story P2.7 — File Watcher

## Overview

File watcher monitors `$RAW_DIR` for new files using WatchService or polling. Creates Document records and calls Coordinator.startChain() to begin the ingestion pipeline automatically.

## Implementation Requirements

- Monitor RAW_DIR directory for file creation events
- Exclude temporary files and hidden files (.tmp, .swp, etc.)
- Create Document record for each detected file
- Call Coordinator.startChain() to queue Ingestor processing
- Log file detection with timestamp and path
- Handle errors (inaccessible directory, permission denied)
- Graceful shutdown of watch service

## Design Options

- WatchService (NIO) — event-driven, portable
- Polling with ScheduledExecutorService — simpler, trades off responsiveness
- External tool integration (e.g., fsnotify) — out of scope

## Configuration

- Watch directory: `$RAW_DIR` from application.yaml
- Poll interval (if polling): configurable in application.yaml
- File filters: configurable patterns to include/exclude

## Acceptance Criteria

- New files in RAW_DIR automatically ingested within reasonable time (~1s)
- Duplicate ingestion prevented (same file not processed twice)
- Error conditions (permission denied, inaccessible dir) logged without crashing
- Watch service shuts down cleanly at application termination
