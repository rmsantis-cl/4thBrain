# Scrapper

Use Firecrawl to retrieve web pages in this project, instead of `WebFetch`.

- Store the referenced URL in `External/Web/References/references.md` (append one entry per URL).
- Store the retrieved HTML and any images under `External/Web/<host>/` (e.g. `External/Web/example.com/`).

All paths above are relative to the Obsidian vault root: `C:\Users\rsant\desar\Local Vault\Local Vault`.
